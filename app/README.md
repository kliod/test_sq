# SQOCH — приложение

Описание сценариев, правил оформления, архитектуры, проверок и времени разработки — в [README репозитория](../README.md).

## Запуск из этой папки

Окружение: Node.js 24.15.0, npm 11.12.1.

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5175 --strictPort
```

- [Успешное оформление](http://127.0.0.1:5175/).
- [Отсутствие мест](http://127.0.0.1:5175/?scenario=sold-out).

## Проверки и сборка

```sh
npm run test
npm run build
```

Результат сборки — `dist/`. Для локального просмотра:

```sh
npm exec vite preview -- --host 127.0.0.1 --port 4173 --strictPort
```

[Короткое демо приложения](sqoch-demo.mp4) — 53 секунды, без звука, с подписями.
