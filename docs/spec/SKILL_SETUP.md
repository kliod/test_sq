# UI/UX Pro Max для Codex: установка и использование

Источник: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill . Команды и заявленная поддержка Codex сверены по README проекта 22.10.2026. **Работоспособность на конкретном ПК не проверялась**; CLI и сценарии установки здесь не исполнялись.

## Предварительная настройка человеком

Выполнять из каталога `app/`, после задачи 00, чтобы скилл появился в проекте приложения, а не в случайной папке.

1. Просмотреть репозиторий, инструкции и разрешения CLI. Перед установкой проверить `node`, `npm`, `python`/`py` и необходимость глобальных прав.
2. Можно использовать рекомендуемый способ репозитория:

```powershell
npm install -g ui-ux-pro-max-cli
uipro init --ai codex
```

Либо без глобальной установки:

```powershell
npx ui-ux-pro-max-cli init --ai codex
```

`npx` может скачать и выполнить внешний пакет. Не разрешать Codex запускать такую команду без вашего согласия. CLI умеет `--dry-run`; сначала изучить предварительный вывод, если выбранная версия поддерживает этот флаг.

3. Проверить наличие каталога `.agents/skills/ui-ux-pro-max/`, файла `SKILL.md` и поискового скрипта, перезапустить сессию Codex при необходимости. **Не предполагать**, что пути совпадут при другой версии, если проверка показала иное.
4. Скрипт поиска требует Python 3.x. На Windows можно использовать `py -3` вместо `python`/`python3`, если так устроено установленное окружение.

## Обязательный шаг: реальное применение на задаче 02

Codex должен открыть `SKILL.md` **до** генерации рекомендаций. При доступном скрипте поиска запустить из каталога `app/`:

```powershell
python .agents/skills/ui-ux-pro-max/scripts/search.py "event ticket checkout booking form accessible responsive" --design-system -p "SQOCH Checkout" -f markdown
python .agents/skills/ui-ux-pro-max/scripts/search.py "form validation error focus" --domain ux
python .agents/skills/ui-ux-pro-max/scripts/search.py "responsive forms" --stack react
```

Если эта версия поддерживает запись на диск, можно отдельно вызвать `--design-system --persist -p "SQOCH Checkout"`. Сохранить именно **свою редакцию** итогового решения в `app/docs/UI_SYSTEM.md`. Не выполнять команды по выдуманному пути: фактический путь определяет установка и документация `SKILL.md`.

## На задаче 05

Повторно прочитать локальный `SKILL.md` и `app/docs/UI_SYSTEM.md`, запросить рекомендации по конкретным нерешенным вопросам: `360 px`, повторяемые поля, ошибка группы, focus states, адаптивная сводка и контраст. Затем изменить CSS/разметку в рамках UI-контракта. Скиллу нельзя изменять типы, правила, состояния оформления, сервис, зависимости и пороги возраста.

## Как подтвердить, что скилл использовался

Создать/обновить `app/docs/SKILL_USAGE.md`:

```md
# UI/UX Pro Max: фактическое применение
- Источник / установленная версия или commit, если доступен: ...
- Путь локального SKILL.md: ...
- Команды или операции, реально выполненные: ...
- Что предложил скилл: ...
- Что принято и почему: ...
- Что отклонено и почему: ...
- Что проверено в браузере (отдельно): ...
```

Если скилл недоступен, **не имитировать применение**: остановить задачи 02/05 и сообщить blocker. Это ограничение относится к выбранному пользователем процессу; для работодателя установка скилла не является обязательным условием.

## Важно

Скилл дает советы по дизайну, но не заменяет проверку браузера и не является спецификацией бизнес-логики. Его рекомендации нужно фильтровать по `docs/spec/UX_BRIEF.md`. Не ставить одновременно альтернативные дизайн-скиллы и не добавлять библиотеку компонентов только потому, что она появилась в примере из скилла.
