## Критерий готовности к сдаче

- Все обязательные R01-R11 соблюдены.
- Успех и sold-out запускаются через один и тот же пользовательский путь, отличаются параметром режима.
- Не теряются данные между review, editing и отказом.
- Snapshot и payload не расходятся; нет дублей при отправке.
- Невалидный возраст не преобразуется в допустимое число; тариф и сопровождение независимы.
- 360 px, ошибки, фокус, клавиатура реально проверены.
- `npm run build` успешен, `npm run test` успешен или причины непроверенного указаны.
- README содержит команды, два URL, фактическое время, ограничения, незавершенные пункты и имена настоящих видеофайлов.
- Запись процесса и короткое демо просмотрены человеком; Codex не должен утверждать это без доказательств.
