# Спецификация SQOCH: содержание

**Начни с [`SPEC.md`](SPEC.md)**: полный исправленный план реализации и правила применения документа.

- `REQUIREMENTS.md` - первичные обязательные требования и допущения.
- `CONTRACTS.md` - финализированные контракты компонентов, модели и жизненного цикла заказа.
- [DECOMPOSITION.md](DECOMPOSITION.md) — правила декомпозиции на основе FSD: текущая структура `app` и `pages/booking`, владельцы, границы, импорты и выделение модулей.
- `ACCEPTANCE.md` - матрица приемочных сценариев.
- `UX_BRIEF.md` - требования к интерфейсу.
- `SKILL_SETUP.md` - использование UI/UX Pro Max в задачах 02/05.

**Правило конфликтов:** требования работодателя важнее инженерных решений. Последующие явно утвержденные уточнения о `app/`, UI/UX Pro Max и проверках по риску действуют в текущем пакете.
